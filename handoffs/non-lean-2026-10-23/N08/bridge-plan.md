# N08 — 原始 hull 与现有主格工具的接合草稿

状态：`STATIC_COMPLETE`（**证明计划**）。全部 5 条引理都是 `UNVERIFIED_MATH`：只有假设、证明草稿、
可能失败的例子和"下一步需要什么原文证据"。**没有一条被形式化，也没有一条被当作已证。**

## 0. 起点与终点

- 起点（仓库里已有的）：`PrincipalProduct.lean`、`PadicPrincipalHull.lean` 在**模型** `ℚ_p^n / ℤ_p^n` 上
  构造了 `λ·O` 型容器、证明了紧性、候选体积为正、Haar 计数公式、无限操作族的共同容器与环的最小主核性。
  这些是**模型层**结论，与原文 `λ·O_{F_v}` 的对应尚未建立（`GAP-core-residue-hull-realization.md` 的四条未实化义务）。
- 终点（本任务要规划的）：把"模型容器"换成"原始允许 hull"，并给出归一化到原始 log-volume 的换算。

## 1. 五条待证引理（每条：假设 → 结论 → 草稿 → 失败例 → 需要的原文证据）

### L1 — 参考格索引有限（把模型体积接到原始体积的前提）
**假设**：`K/ℚ_p` 有限，`O ⊂ K` 为其整数环，`Λ ⊂ K^n` 是一个 `ℤ_p`-格，且 `Λ` 与 `O^n` 在 `K^n` 中互相包含。
**结论**：`[O^n : Λ] < ∞`，且 `vol_Λ = [O^n : Λ] · vol_{O^n}`（同一 Haar 测度下的换算式）。
**草稿**：Hecke 指标公式 + Haar 测度在有限指数子群上的乘法性；`O` 是 `ℤ_p`-自由（局部域，秩 `= [K:ℚ_p]`）。
**可能失败**：`Λ` 只与 `O^n` 在 `K`-张量下同构（向量空间同构）但指标无限——此时换算式不成立，体积比不再是整数。
**需要的原文证据**：III Remark 3.9.5(i) 里 hull 的定义是否**指定**了参考格（若没有，L1 的假设就是我自己加的，必须显式标为新假设）。

### L2 — 共同容器的形状（`λ·O` 只在秩 1 成立）
**假设**：`A, B ⊂ K^n` 是 `O`-格。
**结论**：最小 `O`-格容器是 `A + B`；`A + B` 是自由 `O`-模。
**草稿**：`A+B` 显然包含两者；任何包含两者的 `O`-子模必包含 `A+B`；`O` 是 DVR，故 `A+B` 自由。
**可能失败（关键）**：`n ≥ 2` 时 `A + B` **一般不是** `λ·O^n` 形式——所以"容器是 `λ·O` 型"这个原文说法
在 `n ≥ 2` 需要额外条件。这是一条必须显式记录的落差，不能默认。
**需要的原文证据**：原文 `λ·O` 里的 `λ` 是**逐分量**给的（`λ = (λ_i)`，每分量非零），还是一个整体元素？

### L3 — 拉回容器何时等于原始 hull
**假设**：`n ≥ 1`，`λ = (λ_1,…,λ_n)` 每分量非零，`hull := ∏_i λ_i O`；`C` 是有限商拉回的容器。
**结论**：`C = hull` 当且仅当 `C` 在每个分量上的投影都是 `λ_i O`（即 `C` 不"塌"到任何分量的零）。
**草稿**："⇒"由 `C ⊂ hull` 与两边的自由秩相等推出；"⇐"逐分量比较生成元。
**可能失败**：某个 `λ_i = 0`（原文明确排除，但模型层不排除）时，拉回容器会退化成低维子模，
此时"容器 = hull"的等号两边维度都不同——这正是模型中必须额外的非退化条件。
**需要的原文证据**：III Remark 3.9.5(i) 里"每个分量非零"的**原文句子**（用于把该条件写成假设而不是我补的）。

### L4 — 归一化体积到原始 log-volume
**假设**：L1 的索引 `I = [O^n : Λ]` 有限；参考格上的 Haar 测度 `μ` 固定（`μ(O^n) = 1`）。
**结论**：`vol_orig(λO^n) = -log_p |I| - Σ_i log_p |λ_i|_p`（把 `μ` 与原始 log-volume 对齐后的换算式草稿）。
**草稿**：Haar 乘法性给 `μ(λO^n) = |det λ|_p = ∏|λ_i|_p`；索引修正项 `|I|_p` 由 L1 给出。
**可能失败**：原始 log-volume 的归一化与本式取的 `μ` 不必相同；差一个整体常数，且该常数**不是**纯 p 幂时
换算式会出现非有理因子（与 N06-10 的 `ℚ_p→ℝ` 缺口同源）。
**需要的原文证据**：原文 log-volume 的参考测度定义（哪个格测度为 1）。

### L5 — 所有允许变化落到同一个商上
**假设**：一族允许变化 `G` 每个元都把参考格 `O^n` 映到自身（即 `G ⊂ Aut(O^n)` 的相应子群）。
**结论**：`G` 在有限商 `O^n / p^k O^n` 上的作用良定义，且商上的作用与 `G` 在容器上的作用相容。
**草稿**：良定义性由"保持 `p^k O^n`"直接得到；相容性由作用与包含关系交换得到。
**可能失败（已知的）**：N05 的台账显示 `shared_finite_quotient` 在所有原文条目里都是 `UNRESOLVED`；
若某个允许变化**不**保持参考格，则它根本不在 `Aut(O^n)` 里，L5 的假设失效，商的交换关系无从谈起。
**需要的原文证据**：III 3.11 的 `(Ind1)/(Ind2)/(Ind3)` 是否确实保持同一个有限商（目前无来源支持）。

## 2. 与已有模型结果的关系

模型层的六条结果（紧性、正体积、Haar 计数、共同容器、最小主核性）对应本计划里 L1–L3 的**模型特例**。
也就是说：**模型层证明了"如果参考格就是 `ℤ_p^n` 且 `n=1`，那么一切成立"**；本计划要补的是 `n ≥ 2`
与真实 `O_{F_v}` 两层。这个落差必须在写任何"已有证明"时一并说明。
