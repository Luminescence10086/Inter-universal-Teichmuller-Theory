# OPEN：从单个真实 theta 平移到 étale theta 来源

2026-10-24。本轮已经完成真实 unsigned theta germ 在一次 q 平移下的幂级数、Kummer 类、约化限制类公式，以及算术主格保持的精确判据。没有构造原始 Θ-link。

下一项明确的探索规格（尚未形式化，因此不纳入 fact-tree）：

1. 固定上游 `Iut/EtaleTheta/Theta.lean` 的实际定义 `etaleTheta(U)=U*theta(-U²)`，并固定 s²=q。
2. 为乘法局部坐标 U*(1+Y)，构造对应的幂级数平方代换；需要检验 `PowerSeries.subst` 等实际 API 的合法性和零常数项条件。
3. 将本轮已证的 `G_(q*u)` 恒等式沿该实际代换运输，保留常数和非恒定坐标单位，形成真实 étale theta germ 的 s 平移公式。
4. 再证明同一个 decomposition/specialization 方块中的对应类公式，与固定来源的点值 automorphy 公式逐项核对。不得仅因点值一致就令幂级数相等。

以上4项的目标应由真实定义与箭头构造，而不是用一个要求目标公式为字段的新结构来实现。一次局部几何平移仍区别于跨 Hodge theater 的原始允许复合；后者共同系数作用、绝对 q 标记、合法全局 η 输出仍为独立 OPEN 义务。

本轮常数因子 q*u 的类和整数指数已经被明确保留。后续任何“单位不定性可忽略”的步骤，必须证明对应算术值为1、类为平凡，或提供另一个经验证的充分条件；不能把坐标在 X=0 的值1推广到所有常数修正。
