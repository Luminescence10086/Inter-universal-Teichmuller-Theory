# 第三层：B1–B4 → 原子动作

第二层停在四个拆不动的阻塞。第三层把"处理一个阻塞"拆成**有明确输入、输出、失败判据的原子动作**。
原子动作的判定标准：它必须能交给一个执行者独立完成，且完成与否可以机械核对。

## 3.0 先决动作（来自核验 V6）

### A0｜把候选证据补进仓库

**为什么在最前面**：`candidates/core-transport/CoreTransport/*`（含 `localLog` 的定义）与四个候选目录
（`core-compactness`、`core-log`、`core-normalization`、`core-order-bridge`）在 git 里是空的。
在它们入库前，任何引用它们的 Lean 工件**都不能被任何人复现**，也就无法验收。

- 输入：本地未跟踪文件（8 + 8 + 12 + 4 + 2 个）。
- 输出：一个分支，含五个目录的源文件 + `lakefile.lean` + `lake-manifest.json` + `lean-toolchain`；
  外加一次**干净克隆后的构建记录**（clone → build → 退出码 → 日志）。
- 失败判据：干净克隆构建不通过，则这五个目录的现状**不可作为任何结论的依据**，只能记为 `LOCAL_ONLY_EVIDENCE`。
- 时间盒：一次会话。

## 3.1 处理 B1（log 桥）

### A1｜决定"比较"发生在哪个群上

`localLog` 是 `K → K` 的泛型幂级数；`ℚ_p` 与 `ℝ` 两个实例化之间不存在连续环同构，
所以不能沿用 `localLog_natural`（它要求 `e : K ≃+* L` 且双向连续）。

- 输出：一份 `LogBridge.lean` 草案，含 `logBridge` 的定义域（某个加法子群）、值域、加法性证明义务，
  以及**一对具体 `x, y` 满足 `logBridge (x*y) ≠ logBridge x * logBridge y`** 的乘性反例。
- 失败判据：若"加法性 + 与范数相容"不能在同一个定义域上同时成立，则降级为**只在有限集合上定义**
  （更弱，但足以支撑有限个等式）。降级必须显式登记，不许静默缩小定义域。
- 时间盒：一次会话（含反例）。

### A2｜把"同一幂级数"在 ℝ 一侧落地

这是唯一能把 `localLog` 与真正的实对数接上的一步，也是"`λ` 究竟是桥还是伪装"的最后判据。

- 输出：`K = ℝ` 实例化下 `localLog` 与实对数的关系定理（在收敛域内），或一份"为何做不到"的说明。
- **须先检索 Mathlib 是否已有该幂级数展开**；本文不假设它存在。若不存在，A2 本身就是一个小工程，
  应单独立项而不是塞进 A1。
- 失败判据：若两者只是在收敛域内数值接近而无等式，则 B1 仍然未处理，只能走 P5（弱化路径）。
- 时间盒：检索半天；立项另算。

### A3｜确认 B1 的"不可约"是真的不可约

防止把"我没想到"当成"不可能"。

- 输出：一份清单，列出三条候选桥（域嵌入、加法子群上的 λ、有限集合上的 λ），逐条写"满足哪几条性质、缺哪条"。
- 判据：若存在第四条满足全部所需性质的桥，则 B1 作废（是好事）。**这一条由独立执行者复核，不由 A1 的作者自评。**

## 3.2 处理 B3（权重 `w_v`）

### A4｜把 `w_v` 变成显式参数

- 输出：受影响定理清单 + 改后签名（`w : ι → ℝ` 出现在类型里），以及"本结论相对任意给定 `w` 成立"的措辞模板。
- 判据：改后签名里**看不到**"原文的全局 log-volume"这类无参数说法；所有相关句子都能指出 `w` 在哪。
- 时间盒：一次会话。

### A5｜证"权重不可省"

- 输出：取两个不同的 `w`，找出结论随之改变的具体实例（若找不到，说明结论其实不依赖 `w`，那要改的是定理而非措辞）。
- 判据：反例必须能在 CLI 下重放。
- 时间盒：一次会话。

## 3.3 处理 B2（环级认同）

### A6｜环级拉回格与"有限指数不够"的反例

- 输出：(i) 从 `Z_p^n` 模型拉到 `O_{F_v}` 的格定义与有限指数假设；(ii) 一个"指数有限但不保格"的例子。
- 判据：(ii) 必须存在，否则"有限指数"就是充分的，第二层 B2 的措辞要改强。
- 时间盒：一次会话。

## 3.4 处理 B4（常数 `c`）

### A7｜`c` 与 `S` 无关，否则降级

- 输出：要么证明 `c` 不依赖 `S`，要么给出一个 `S`-依赖的构造。二者必居其一，不能只写"假设"。
- 判据：若给出 `S`-依赖的构造，则 N06-01 的"归约为一条标量方程"作废，P1 需要重写。
- 时间盒：两次会话。

# 第四层：原子动作 → 可交付工件

第四层把每个原子动作变成**一个有机械验收标准的交付物**。判据只用三类可复算的东西：
CLI 退出码与诊断数、公理导出、文件哈希；编辑器 0 error/0 warning 单列为"复核方步骤"，不由交付方自评。

## 4.1 交付物清单

| 工件 | 前置 | 机械验收（可复算） | 失败即停条件 | 时间盒 |
|---|---|---|---|---|
| D0 候选目录入库 + 干净克隆构建 | 无 | 新克隆上 `lake build` 退出 0；日志含 clone 的 commit SHA | 构建不过 → 五个目录标记 `LOCAL_ONLY_EVIDENCE`，后续全部引用降级 | 1 次会话 |
| D1 `logBridge` 草案 + 乘性反例 | D0 | `lake env lean -DwarningAsError=true` 零诊断；反例可重放；公理 ⊆ {propext, Classical.choice, Quot.sound} | 定义域无法同时满足加法性与范数相容 → 降级到有限集合，并显式登记 | 1 次会话 |
| D2 ℝ 侧 `localLog` = 实对数（或"做不到"说明） | D1 | 同上；若为说明则须附 Mathlib 检索记录（检索词、命中、结论） | 无等式只有数值接近 → B1 未处理，转 P5 | 检索半天，立项另计 |
| D3 B1 不可约性的三桥对照表 | D1 | 逐条列性质与缺失；**由独立执行者复核** | 找到第四条桥 → B1 作废 | 半次会话 |
| D4 `w_v` 参数化 + 签名清单 | D0 | 签名里 `w` 可见；旧无参数措辞清零（grep 计数 = 0） | 仍有"原文 log-volume"式无参数句子 → 不许交付 | 1 次会话 |
| D5 权重不可省的实例 | D4 | CLI 重放退出 0；两个 `w` 给出不同结论 | 找不到差异 → 改定理，不改措辞 | 1 次会话 |
| D6 环级拉回格 + 有限指数不够的反例 | D0 | 同上；反例必须跑通 | 反例不存在 → B2 措辞改强 | 1 次会话 |
| D7 `c` 与 `S` 无关或反例 | D0 | 二者必居其一，交付里必须明确写是哪一个 | 只写"假设" → 交付退回 | 2 次会话 |

## 4.2 交付包的公共字段

每个工件交一份 `bundle.json`：`task_id`、`head_commit`（完整 SHA）、`base_commit`、`changed_paths`、
`commands_run`（argv / 退出码 / 耗时 / 日志 sha256）、`axioms`、`unresolved`、
`lean_run`、`editor_run`、`fact_tree_admitted=false`。

**四道容易作弊的地方，逐条设判据**：

1. **日志末行 ≠ 退出码**：退出码必须是父进程 `wait()` 得到的（E1 那次的教训）。
2. **自报"零告警"不算**：必须给 `-DwarningAsError=true` 的退出码 0 与空输出。
3. **公理导出必须逐条列**：不许写"公理干净"；要列 `#print axioms` 的原始输出。
4. **编辑器观察不由交付方自评**：`editor_run.observed=false` 是合法值，谎报为 true 是退回理由。

## 4.3 何时放弃一条路径（决策规则）

倒推的价值在于**尽早知道哪条路走不通**。规定三条止损：

- **B1 止损**：D1 + D2 两轮内拿不出"加法性 + 与范数相容"的桥，且 D3 找不到第四条桥 →
  停止 P1/P3/P4，只保留 P2（近似输出）与 P5（弱化）。
- **B2 止损**：D6 的反例不存在（即有限指数竟然充分）→ 立刻把 B2 从阻塞降为已解，并把 P1 的环级义务删掉。
- **B4 止损**：D7 给出 `S`-依赖的 `c` → N06-01 作废，P1 的"归约为标量方程"整段重写。

## 5. 边界

- 本文仍是设计。八个工件没有一个被完成，核心 GAP 全部 OPEN。
- D0 是唯一"不做就什么都别做"的工件：证据不在库里，任何后续交付都不可复现。
- 任何工件若要求改变 G0、核心依赖或验收用例，必须单独走新设计审查。
